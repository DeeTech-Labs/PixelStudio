# Changelog

Все заметные изменения PixelStudio документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [0.2.1] - 2026-06-10

### Added
- Централизованное логирование с ротацией файлов и уровнями детализации
- Минидамп Windows при критическом сбое или `qFatal` для диагностики
- Кнопка «Открыть папку логов» в настройках (раздел «Данные»)
- Поддержка загрузки SVG и SVGZ
- Единый список форматов изображений во всех диалогах открытия и экспорта

### Changed
- Загрузка и сохранение изображений переведены на общий слой ввода-вывода с единообразными сообщениями об ошибках

## [0.2.0b] - 2026-06-09

### Changed
- Ссылка на документацию в диалоге «О программе» ведёт на основной README репозитория

## [0.2.0] - 2026-06-09

### Added
- Вкладка настроек внутри приложения с редактором цветов подсветки синтаксиса
- Переводы в формате JSON и поддержка пользовательских языков из AppData
- Отображение версии Major.Minor.Patch в интерфейсе
- Иконка приложения в проводнике Windows и на панели задач

### Changed
- Переименование исполняемого файла в `PixelStudio.exe`
- Полный редизайн интерфейса в стиле retro-pixel: оболочка, рабочая область, инспектор
- Переработан welcome-экран
- Бесшовное переключение вкладок студии
- Пайплайн конвертера: превью в памяти, быстрее восстановление вкладок после перезапуска
- Обновлены диалог «О программе», меню и диалоги оболочки
- Единый каталог форматов пикселей дисплея

### Fixed
- Исправления сохранения и загрузки формата проектов

## [0.1.0] - 2026-06-04

### Added
- Первый публичный релиз PixelStudio — десктопная студия конвертации изображений в прошивочный код для OLED, TFT и других embedded-дисплеев
- Конвертер: профили дисплея, дизеринг, подбор палитры, превью результата
- Рабочая область со вкладками и инспектором параметров
- Экспорт в C/C++ заголовки и бинарные форматы, пакетный экспорт и сборка спрайт-атласов
- Сохранение и загрузка проектов
- Русская и английская локализация интерфейса
- Установщик Windows для установки приложения без ручной сборки

### Fixed
- Исправления установщика и сценария установки перед публикацией релиза
