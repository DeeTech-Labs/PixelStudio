## [0.1.0] - 2026-06-04

### Added

- Desktop app: images to C/C++ arrays for OLED/TFT displays.
- Qt 6 Quick UI: welcome, multi-tab studio, inspector panels.
- Display profiles, rasterization, code generation.
- Batch export, sprite atlas, watch folder, header import.
- English and Russian UI (`i18n/`).
- Windows installer (`installer/build-installer.ps1`, Inno Setup).
